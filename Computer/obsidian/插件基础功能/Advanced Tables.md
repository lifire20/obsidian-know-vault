``Advanced Tables`` 是一个能极大地改善在 Obsidian 中编辑和阅读 Markdown 表格体验的插件。它通过提供类似电子表格的交互方式和自动化格式，让原本繁琐的表格操作变得直观高效。

### ✨ 核心功能一览

| 功能类别        | 具体功能               | 说明                                                                  |
| :---------- | :----------------- | :------------------------------------------------------------------ |
| **🧭 高效导航** | **“类 Excel”的键盘导航** | 使用 <kbd>Tab</kbd> 键向右移动单元格，<kbd>Enter</kbd> 键进入下一行，就像在 Excel 中一样流畅。 |
|             | **快捷键支持**          | 例如，`Ctrl/Cmd + Shift + D` 可快速打开表格控制侧边栏，进行图形化操作。                     |
| **✍️ 便捷编辑** | **自动格式化**          | 输入时自动对齐列宽、调整间距，保证源码阅读和预览视图都整洁美观。                                    |
|             | **行列操作**           | 通过工具栏按钮或快捷键，轻松 **添加、删除、移动、复制** 行和列，无需手动修改语法。                        |
|             | **列对齐**            | 支持将整列内容设置为 **左对齐、居中或右对齐**。                                          |
| **🧮 数据处理** | **公式计算**           | **支持基础的电子表格公式**，如 `SUM`、`AVERAGE` 等，可直接在表格下方计算结果，数据笔记也能实现自动汇总。      |
|             | **表格排序**           | 可以根据指定列的数值或字母顺序，对表格行进行 **升序或降序排列**。                                 |
|             | **导出为 CSV**        | 能将 Markdown 表格一键导出为 `.csv` 文件，方便用 Excel 或 Numbers 等其他软件打开处理。        |

### 🔧 适用场景

这个插件特别适合以下场景：
*   **数据记录与跟踪**：制作和更新 **预算表、项目进度跟踪、阅读清单** 或简单的个人数据库时，能快速调整结构、排序数据。
*   **笔记中的结构化信息**：在整理 **产品参数对比、课程表、会议纪要** 等需要对齐的内容时，自动格式化让笔记始终美观，公式功能还能自动完成合计、平均值等计算。
*   **轻度数据分析**：在知识库中对笔记中的小规模数据集进行 **排序和简单运算**，无需切换到外部电子表格软件。

### 🚀 如何开始使用

1.  **安装插件**：
    *   进入 Obsidian **设置 → 社区插件**，关闭安全模式后，搜索 “**Advanced Tables**” 并安装启用。
2.  **创建表格**：
    *   在笔记中输入一个竖线 `|` 符号，然后输入表头内容并按 <kbd>Tab</kbd> 键。继续输入并按 <kbd>Tab</kbd> 完成表头后，按 <kbd>Enter</kbd> 键即可开始填写第一行。
3.  **使用工具栏**：
    *   按快捷键 `Ctrl/Cmd + Shift + D` 打开侧边栏的表格控制面板。这里的按钮可以帮你完成大部分操作，例如对齐、排序、插入或删除行列。

> **移动端说明**：插件同样支持 Obsidian Mobile，但 `Tab` 和 `Enter` 的导航功能不可用。作为替代，可以将“下一个单元格”和“下一行”命令添加到手机工具栏。

### 💎 总结

总的来说，Obsidian 的 `Advanced Tables` 插件是一款必备的效率工具。它巧妙地结合了 Markdown 的纯文本优势与电子表格的交互便利性，让表格真正成为你知识网络中高效、灵活的一部分。
