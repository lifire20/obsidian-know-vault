1.先把虚拟机关机，然后选中要扩容的虚拟机，点击设置-硬盘-扩展，把数值调整为你希望的大小，然后**确定**
2.开启虚拟机，输入命令
```
lsblk
```
观察这三行：
```
sda      8:0    0    30G  0 disk 
├─sda1   8:1    0     1M  0 part 
└─sda2   8:2    0    20G  0 part /

```
发现**磁盘 `sda`** 总大小是 **30G**，**分区 `sda2`** 只有 **20G**，挂载在 `/`（根目录），还有 **约 10G 未分配空间**（30G - 20G - 1M ≈ 10G），所以需要分配给sda2。
2.输入命令
```
df -hT /
```
检查文件系统类型
输出类似
```
lv@Slave1:~$ df -hT /
文件系统       类型  大小  已用  可用 已用% 挂载点
/dev/sda2      ext4   20G   19G  461M   98% /
```
3.如果没有安装分配工具，需要安装
输入命令
```
sudo apt update && sudo apt install cloud-guest-utils -y
```
来安装
4.输入命令
```
sudo parted /dev/sda print free
```
观察可用空间起始点情况，输出类似：
```
lv@Slave1:~$ sudo parted /dev/sda print free
[sudo] lv 的密码： 
型号：VMware, VMware Virtual S (scsi)
磁盘 /dev/sda: 32.2GB
扇区大小 (逻辑/物理)：512B/512B
分区表：gpt
磁盘标志：

编号  起始点  结束点  大小    文件系统  名称  标志
      17.4kB  1049kB  1031kB  可用空间
 1    1049kB  2097kB  1049kB                  bios_grub
 2    2097kB  21.5GB  21.5GB  ext4
      21.5GB  32.2GB  10.7GB  可用空间
```
发现可用空间的起始点在编号2（sda2）的结束点后面，这样就可以直接扩容了。
5.输入命令
```
sudo growpart /dev/sda 2
```
来扩展分区
输出类似于：
```
lv@Slave1:~$ sudo growpart /dev/sda 2
CHANGED: partition=2 start=4096 old: size=41936896 end=41940991 new: size=62910431 end=62914526
```
6.输入命令
```
sudo resize2fs /dev/sda2
```
来扩展ext4文件系统
输出类似于：
```
lv@Slave1:~$ sudo resize2fs /dev/sda2
resize2fs 1.47.0 (5-Feb-2023)
/dev/sda2 上的文件系统已被挂载于 /；需要进行在线调整大小
old_desc_blocks = 3, new_desc_blocks = 4
/dev/sda2 上的文件系统大小已经调整为 7863803 个块（每块 4k）。
```
7.检查结果
输入命令
```
df -h /
```
输出类似于：
```
lv@Slave1:~$ df -h /
文件系统        大小  已用  可用 已用% 挂载点
/dev/sda2        30G   19G  9.9G   65% /
```
发现现在已经扩容成功了。
