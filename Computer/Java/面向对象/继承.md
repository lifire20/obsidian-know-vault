## 格式
extends 关键字用于让两个类建立起继承关系
```
public class Student extends Person{}
```
Student 就是子类（派生类），Person 就是父类（基类或超类）

## 优点
可以把重复代码抽取到父类中，可以增加和父类不同的属性
## 使用场景
当类与类之间存在相同的内容，并满足子类是父类的一种，就可以考虑使用继承。
## 特点
1.只能单继承，一个子类只能继承一个父类。
2.可以多层继承，子类 A 继承父类 B（直接父类），父类 B 继承父类 C（间接父类）
3.object：每一个类都间接或直接地继承与 object 类
4.子类只能访问父类中非私有的成员
### 成员变量的访问特点
就近原则：谁离得近就用谁
```
public class Fu{
	String name "Fu";
}
public class zi extends Fu{
	String name "Zi";
	public void ziShow(){
		String name "zishow";
		System.out.println(name);//输出zishow
		System.out.println(this.name);//输出Zi
		System.out.println(super.name);//输出Fu
	}
}
```
this 关键字，表示本类成员变量
super 关键字，表示父类（不会查看子类，直接查看父类）

### 成员方法的访问特点
也是就近原则
注意：方法在调用的时候需要有一个调用者，所以当一个类中出现单独的方法比如 `eat()` 的时候，前面其实有一个隐含的 this 关键字即 `this.eat()`。

### 构造方法的访问特点
1.父类中的构造方法不能被子类继承，可以通过 super 调用
2.子类中所有构造方法默认先访问父类中的无参构造，再执行自己
（因为子类在初始化的时候，有可能会使用到父类中的数据，如果父类没有完成初始化，子类就无法使用父类的数据）
子类在初始化之前，一定要调用父类构造方法先完成父类数据空间的初始化
