对象代表什么，就得用关键字([[基础概念1]])封装对应的数据，并提供数据对应的行为
# private 关键字
1.权限修饰符[[权限修饰符]]
2.可以修饰成员（变量和方法）
3.被修饰的只能在==本类==访问

为了让合法数据可以被赋值，可以用 set/get 
![[Pasted image 20260918142300.png]]
set 方法是给成员变量赋值的，需要传入合法数据，在本类赋值给成员，不合法的时候不能传入
get 方法是对外提供成员变量的值的，把符合条件的赋值返回

# this 关键字
局部变量是指定义在方法内部（含方法参数）的变量，只在方法内有效，如果不用 this 修饰，那么在方法中访问相同名字的变量的时候，会采用就近原则，即方法内部的局部变量
 用 this 修饰的话，就会变成成员变量，赋值的时候会赋给成员变量。
 ```
 class peo{
 private String name;
 
 public void setName(String name){
 this.name=name;//右边的没有this修饰，表示的就是测试类调用set方法传入的名字。=左边的被this修饰，表示的是peo类中被private修饰的成员变量name。这个表达式表示把传入的名字赋值给成员变量。
 }
 
 public String getName(){  
     String name="吕盼盼";  
     System.out.println(name);  //输出吕盼盼
     return this.name;  //输出set传入的
 }
 
 }
 ```
