[[接口]]
##### 基本形式
```
接口类型 j=new 实现类对象();
```
eg：
```java
interface Animal {
    void sound();
}

class Dog implements Animal {
    @Override
    public void sound() {
        System.out.println("汪汪");
    }
}

class Cat implements Animal {
    @Override
    public void sound() {
        System.out.println("喵喵");
    }
}

public class Test {
    public static void main(String[] args) {
        Animal a1 = new Dog(); // 接口引用指向实现类对象
        Animal a2 = new Cat();
        a1.sound(); // 输出：汪汪
        a2.sound(); // 输出：喵喵
    }
}
```

##### 方法参数多态
当一个方法的参数是接口时，可以传递接口所有实现类的对象，这种方式称之为接口多态
eg：
```java
public void makeSound(Animal animal) {
    animal.sound(); // 传入 Dog 就汪汪，传入 Cat 就喵喵
}
```

##### 集合多态
用接口类型作为集合元素类型，存放不同实现类对象，遍历时统一调用。

```java
List<Animal> list = new ArrayList<>();
list.add(new Dog());
list.add(new Cat());
for (Animal a : list) {
    a.sound(); // 各自执行自己的实现
}
```

##### 返回值多态
方法返回接口类型，实际返回某个实现类对象，调用方无需关心具体类型。
```java
public Animal createAnimal(String type) {
    if ("dog".equals(type)) return new Dog();
    return new Cat();
}
```

##### 默认方法的多态
默认方法同样参与多态：实现类若重写了默认方法，调用时执行重写版本；若未重写，执行接口中的默认实现。
```java
interface Greeting {
    default void hello() { System.out.println("默认 Hello"); }
}
class A implements Greeting { }
class B implements Greeting {
    @Override
    public void hello() { System.out.println("B 的 Hello"); }
}
// new A().hello() -> 默认 Hello
// new B().hello() -> B 的 Hello
```
