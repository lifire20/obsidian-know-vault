# 双列集合的特点
![[Pasted image 20261117143715.png]]
1. 双列集合一次需要存一对数据，分别为键和值
2. 键不能重复，值可以重复
3. 键和值是一一对应的，每一个键只能找到自己对应的值
4. 键加值这个整体，我们称之为`键值对`或者`键值对对象`，在 Java 中叫做 `entry 对象`

# Map 的常见 API
 MAP 是双列集合的顶层**接口**，它的功能是全部双列集合都可以继承使用的
 ![[Pasted image 20261117145505.png]]
添加元素
```java
Map<String,String> m=new HashMap<>();  
m.put("宗煦","奚荣");  
m.put("应温瑜","童越");  
String value=m.put("应温瑜","扈玉和");//返回被覆盖的值  
String v2=m.put("应温瑜","汤宿安");  
  
System.out.println(m);//{宗煦=奚荣, 应温瑜=扈玉和}  
System.out.println(value);//童越  
System.out.println(v2);//扈玉和
```
put 方法的底层是创建一个 Entry 对象
> [!important] 
> 在添加数据的时候，如果键**不存在**，那么直接把键值对对象添加到 Map 集合当中,方法返回 null
> 在添加数据的时候，如果键是**存在的**，那么就会把原有的键值对对象覆盖，会把被覆盖的值进行返回
# Map 的遍历

## 通过键找值来遍历

**获取所有的==键==，把这些键放到一个单列集合当中**
```
Map<String,String> m=new HashMap<>();  
m.put("宗煦","奚荣");  
m.put("应温瑜","童越");  
m.put("汤宿安","扈玉和");  
  
//获取所有的键，把这些键放到一个单列集合当中  
Set<String> keys = m.keySet(); 
```

> [!tip]- 三种遍历方式示例
> ### for 循环
> ```
> for (String key:keys){  
>     //利用MAP集合中的键获取对应的值  
>     String v=m.get(key);  
>     System.out.println(key+"="+v);  
> }
> ```
> ### 迭代器
> ```
> Iterator<String> it=keys.iterator();  
> while(it.hasNext()){  
>     String key =it.next();  
>     String v= m.get(key);  
>     System.out.println(key+"="+v);  
> }
> ```
> ### Lambda
> ```
> m.forEach((s, s2) ->System.out.println(s+"="+s2));
> ```

## 通过键值对来遍历
**获取所有==键值对对象==，返回一个 set 集合**
```
//获取所有键值对对象，返回一个set集合
Set<Map.Entry<String, String>> entries = m.entrySet();  
//遍历集合得到每一个键值对对象
```

> [!tip]- 三种遍历方式示例
> **增强for 循环**
> ```
> for (Map.Entry<String, String> entry : entries) {  
> //利用Entry调用get方法获取键和值并打印
>     String key = entry.getKey();  
>     String value = entry.getValue();  
>     System.out.println(key+"="+value);  
> }
> ```
> **Lambda 表达式**
> ```
> entries.forEach(entry -> {  
>         String key = entry.getKey();  
>         String value = entry.getValue();  
>         System.out.println(key + "=" + value);  
>   
> });
> ```
> **迭代器**
> ```
> Iterator<Map.Entry<String, String>> it = entries.iterator();  
> while(it.hasNext()){  
>     Map.Entry<String, String> en=it.next();  
>     System.out.println(en.getKey()+"="+en.getValue());  
> }
> ```

HashMap 和 TreeMap 的区别就是是否可排序，后者可排序。
LinkedHashMap 是存取有序，默认按插入顺序遍历，可切换为访问顺序，而 TM 是比较出来的，可以自定义排序规则。
TreeMap 要求 key 可比较，放不可比较的 key 会抛 ClassCastException；LinkedHashMap 对 key 没有任何比较要求
