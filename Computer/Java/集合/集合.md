## Collection
  Collection 是单列集合的祖宗**接口**，它的功能是全部单列集合都可以继承使用的。
### 常用方法
  
![[Pasted image 20261106133846 copy.png]]

Collection 的实现类是 Arraylist,要实现其中的方法，必须先创建它的实现类的对象.
格式
```
Collection<String> coll=new ArrayList<>();
ArrayList<String> coll=new ArrayList<>();
```
- 往 list 系列集合添加数据的时候，返回值就是 true。
	往 Set系列集合添加数据的时候，当集合中元素已存在则返回 False ，元素不存在返回 True。
- 调用 remove方法的时候，不能通过索引进行删除，只能通过元素的对象进行删除。
```
coll.remove("aaa")//不能用coll.remove(1);
``` 
- Contains 的方法的底层是依赖以 equals 方法进行判断是否存在的。所以如果集合中存储的是自定义的对象也想通过 contents 方法来判断是否包含，那么在 JavaBean 类中一定要重写 equals 方法。
### 遍历方式

#### 迭代器遍历
这个是不依赖索引的
![[Pasted image 20261108145010 copy.png]]
代码：
```java
Iterator<String> it=coll.iterator();//创建指针，默认指向0索引  
while(it.hasNext()){//判断是否有元素。  
    String str= it.next();//获取元素并移动指针。  
    System.out.println(str);//打印获取到的元素。  
}
```
- 迭代器遍历完毕，指针不会复位，要想再次遍历，需要重新创建一个迭代器。
- 循环中只能使用一次 next（）方法，因为这个方法每调用一次都要移动一次指针。如果针对一个有五个元素的集合，在方法体中调用了两次，那么在最后一次循环的时候，第 2 次就无法获取到元素，因为第 1 次的 next（）移动了指针，指向了集合外。
- 迭代器遍历时不能用集合的方法进行增加或者删除。可以用迭代器提供的 remove 方法删除。
#### 增强 for 循环
- 底层就是迭代器，为了简化迭代器的代码书写的。
- 所有的单列集合和数组可以用增强 for 循环进行遍历。
格式
```
for（元素的数据类型 变量名：数组或集合）{

}
```

```
for(String s:list){
	Sout(s);
}
```

```
int [] arr={1,2,3,4};  
for (int i : arr) {  
    System.out.println(i);  
}
```

### Set 系列集合
- 添加的元素是无序，不重复，无索引的。
	- 存取顺序不一致
	- 不重复：意味着可以去除重复
	- 无索引：没有带索引的方法，所以不能使用普通 for 循环遍历，也不能通过索引来获取元素
#### Set 集合的实现类
[[HashSet]]:无序，不重复，无索引
[[LinkedHashSet]]：有序，不重复，无索引
[[TreeSet]]：可排序，不重复，无索引
*Set 接口中的方法基本上与 Collection 的 API 一致，可继承其常用方法*
```java
public static void main(String[] args) {  
    Set<String> s=new HashSet<>();  
    boolean r1=s.add("吕瑞彤");//返回boolean  
    boolean r2=s.add("吕瑞彤");  
    System.out.println(r1);//true  
    System.out.println(r2);//false  
    System.out.println(s);//只有吕瑞彤  
}
```
#### 遍历
**迭代器遍历**
```java
s.add("小红");  
s.add("小兰");  
s.add("小明");  
s.add("小张");  
  
Iterator<String> it=s.iterator();  
while(it.hasNext()){  
    String str=it.next();  
    System.out.print(str);//小明小红小兰小张(无序的)  
}
```
**增强 for**
```java
for (String str : s) {  
    System.out.print(str);//小明小红小兰小张(无序的)  
}
```
**Lambda 遍历**
```
s.forEach(str ->System.out.println(str));
```
