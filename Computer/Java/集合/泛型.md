## 泛型接口
格式：
```java
修饰符 interface 接口名<类型>{
}
```
使用方式：
1.实现类延续泛型，创建对象时再确定
```java
public class MyArrayList3<E> implements List<E> {
}
//test文件
MyArrayList3<String> list1 =new MyArrayList3<>();  
list.add("1");
```

2.实现类给出具体类型
```java
public class MyArrayList2 implements List<String> {
}
//test文件
MyArrayList2 list =new MyArrayList2();  
list.add("1");

```

## 泛型的继承
**泛型不具备继承性，但是数据具备继承性**
```java
package demo15;  
  
import java.util.ArrayList;  
  
public class fanxingjicheng {  
    public static void main(String[] args) {  
        //创建集合的对象  
        ArrayList<ye> list1=new ArrayList<>();  
        ArrayList<fu> list2=new ArrayList<>();  
        ArrayList<zi> list3=new ArrayList<>();  
        /*泛型不具备继承性*/
        method(list1);//不报错  
        method(list2);//报错  
        method(list3);//报错  
        /*数据具备继承性*/  
		list1.add(new ye());  
		list1.add(new fu());  
		list1.add(new zi());
		  
		list2.add(new ye());//报错  
		list2.add(new fu());  
		list2.add(new zi());  
		  
		list3.add(new ye());//报错  
		list3.add(new fu());//报错  
		list3.add(new zi());
    }  
    public static void method(ArrayList<ye> list){  
    }  
}  
  
class ye{}  
class fu extends ye{}  
class zi extends fu{}
```

## 泛型的通配符
就是一个问号
- `？`：表示一个未知类型，它可以进行类型的限定。等价于 `？ extend Object`
- `？ extend E`：表示可以传递 E 或者 E 所有的子类类型
- `？ super E`：表示可以传递 E 或者 E 所有的父类类型
[[泛型通配符单独E和问号的区别]]： E 是定义泛型时起的类型变量名，后续方法体内可以当成类型来使用，而问号只能当成 object 来使用，是使用泛型时用的

如果我们在定义类方法接口的时候，类型不确定，就可以定义泛型类，泛型方法，泛型接口。
如果类型不确定，但是知道以后，只能传递某个继承体系中的，就可以使用泛型的通配符。
