#### 忽略大小写的正则
- 用小括号 ：`(\\d|X|x)` 表示要么是数字要么是大小写的 x
- `(?i)abc`：这时候“abc”、“Abc”、“ABC”都能匹配上
	`a((?i)b)c` 表示只有 b 可以忽略大小写

## 爬虫

Partten：表示正则表达式
Matcher：文本匹配七，作用按照正则表达式的规则去读取字符串，从头开始读取。在大串中去寻找复合匹配规则的子串。
#### 本地爬虫
```java
public static void main(String[] args) {  
  
    String str="Java自从95年问世依赖，经历了很多版本，目前企业中用的最多的是Java8何Java11，因为这两个是长期支持版本，下一个长期支持版本是Java17，相信在未来不久Java17也会逐渐登上历史的舞台";  
    //获取正则表达式的对象  
    Pattern p=Pattern.compile("Java\\d{0,2}");  
  
    //获取文本匹配器的对象  
    //str:大串  
    //p：规则  
    //m要在str中找到满足p规则的子串  
    Matcher m=p.matcher(str);  
  
    while (m.find()){  
        //除了返回结果，还会在底层记录子串的起始索引和结束索引+1  
        //根据find方法记录的索引来读取字符串  
        String s1=m.group();  
        System.out.println(s1);  
    }  
}  
```
#### 贪婪爬取和非贪婪爬取
是 Java 中默认的爬取方式，表示尽可能多的获取数据，反之则为非贪婪爬取
**贪婪匹配**：只写+或*
**非贪婪匹配**：`+？`，` *？`

### 分组
就是一个小括号。
分组有组号，从 1 开始，连续不断，以左括号为基准，从左到右为第一组第二组等等，没有优先级。
**捕获分组**
内部使用：
`\\组号` ：表示把第 x 组的内容拿出来再用一次
