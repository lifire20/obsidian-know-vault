[[泛型和包装类]]
### 定义
是指基本数据类型所对应的引用数据类型，即变成一个对象
![[Pasted image 20261031171754.png]]
Integer 类对-128 到127 进行了优化（和 BI 大整数 与 BD 大小数 一样），超过 这个范围就会创建新的对象

### 拆箱装箱
**自动装箱**：把基本数据类型自动变成其对应的包装类。
**自动拆箱**：把包装类自动变成其对象的基本数据类型。
```
Integer i1=10;//自动装箱  
  
Integer i2=new Integer(10);  
int i=i2;//自动拆箱
```
