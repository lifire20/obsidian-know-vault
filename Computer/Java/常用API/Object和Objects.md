#### 克隆
如果一个接口里面没有抽象方法，就表示当前的接口是一个标记性接口，Cloneable 就是这样,一旦被实现了,那么当前类的对象就可以被克隆,否则不能克隆
##### 浅克隆
把 A 对象的基本数据类型和引用数据类型都完全拷贝给 B 对象（包括数组的地址值，也就是两个对象操作的是同一个数组）

**Object 类的 clone() 方法默认实现的是浅拷贝。**
##### 深克隆
把 A 对象的基本数据类型拷贝过来，字符串复用，引用数据类型则重新创建新的

要深克隆，需要再次重写 clone 方法（就是把一个数组里的数据放在一个新数组中）
或者使用第三方 Gson工具来实现（先把对象转换成 Json 字符串，在把 Json 字符串变回对象，相当于这个对象把数组又创建了一遍，这样就可以让两个对象不操作同一个数组了）
