### 简单计算器的实现
```
class demo4 {  
    public static void main(String[] args){  
        getSum(10,20);//实参  
    }  
    public static void getSum(int num1,int num2){  
        int sum=num1+num2;  
        System.out.println(sum);  
    }  
}
```

### 形参和实参
1.形参：形式参数，是指方法定义中的参数
2.实参：实际参数，方法调用中的参数

### 带参数方法的实现
求圆面积
```
package com.itheima.demo1;  
class demo4 {  
    public static void main(String[] args){  
        double r;  
        r=1;  
        double num=getCir(r);  
        System.out.println(num);  
    }  
    public static double getCir(double r1){  
        return r1*r1*3.14;  
    }  
}
```
