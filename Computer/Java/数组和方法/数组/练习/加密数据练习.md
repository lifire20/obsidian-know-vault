### 代码实现
```
package com.itheima.demo1;  
  
import java.util.Scanner;  
  
class demo4 {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        System.out.println("请输入需要加密的密码：");  
        int num = sc.nextInt();  
        /**  
         * 1.得到输入数字的个数（count）  
         * 2.把数字存进数组中  arr[count]  
         * 3.把每个数字+5再对10取余，逆序输出  
         * 4.连接数组内数字  
         */  
        int count = 0, temp = num;  
        for (int i = 0; temp > 0; i++) {  
            temp = temp / 10;  
            count++;  
        }  
        int[] arr = new int[count];  
        getNum(num, arr);//得到每位数  
        sumNum(arr);//加密操作  
        for (int i = 0; i < arr.length; i++) {  
            System.out.print(arr[i]);  
        }  
    }  
  
    public static void getNum(int num, int[] arr) {  
        arr[0] = num % 10;  
        for (int i = 1; i < arr.length; i++) {  
            num = num / 10;  
            arr[i] = num % 10;//逆序存入  
        }  
    }  
  
    public static void sumNum(int[] arr1) {  
        for (int i = 0; i < arr1.length; i++) {  
            arr1[i] += 5;  
            arr1[i] = arr1[i] % 10;  
        }  
    }  
}
```
### 重要思想
反向推导

这道题需要把数字一个个存入数组中，那就要知道数组长度，为了得到数组长度，就要引入变量 count 来计算长度，然后再定义数组。
