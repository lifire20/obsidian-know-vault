### 问题
定义一个数组 arr[1],初始化为 1，2，3，4，5，交换收尾索引对应的元素
### 分析
1.交换前：1，2，3，4，5
交换后：5，4，3，2，1
2.设计循环遍历数组，把第一个索引的数据存到一个临时变量中，再把最后一个索引的数存在第一个索引中，此时最后一个索引为空，把刚才的临时变量村的数据给最后一个索引，这时候就完成了第一个和最后一个索引数据的交换。
3.当遍历到中间数据的时候，就可以停止循环了，否则会重新交换一遍。
![[交换索引数据.excalidraw]]
### 代码实现
```
package com.itheima.demo1;  
  
class demo3 {  
    public static void main(String[] args) {  
        int[] arr = {1,2,3,4,5};  
  
        for (int i = 0,j=4; i < j; i++,j--) {  
            int temp=arr[i];  
            arr[i]=arr[j];  
            arr[j]=temp;  
  
        }  
        for (int i = 0; i < arr.length; i++) {  
            System.out.println(arr[i]);  
        }  
    }  
}
```
