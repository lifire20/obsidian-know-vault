# 代码实现
```java
package com.itheima.demo1;  
  
import java.util.Random;  
  
//把奖金存进数组  
//循环随机抽取数据  
class demo5 {  
    public static void main(String[] args) {  
        Random r=new Random();  
        int [] arr={2,888,588,1000,10000};  
        int[] arr2=new int[arr.length];  
        for (int i = 0; i < arr.length; ) {  
            int price=r.nextInt(5);  
            if(!ran(arr2,arr[price])){  
                arr2[i]=arr[price];  
                i++;  
            }  
        }  
        for (int i = 0; i < arr2.length; i++) {  
            System.out.println(arr2[i]);  
        }  
            }  
  
    public static boolean ran(int[] arr,int price){  
        for (int i = 0; i < arr.length; i++) {  
  
            if(price==arr[i]){  
                return true;  
            }  
        }  
        return false;  
    }  
  
}
```
# if 条件语句成因
这里的 `if` 语句是：

```java
if(!ran(arr2, arr[price])){
    arr2[i] = arr[price];
    i++;
}
```

## 关键点：`ran` 方法的返回值含义

先看 `ran` 方法：

```java
public static boolean ran(int[] arr, int price){
    for (int i = 0; i < arr.length; i++) {
        if(price == arr[i]){
            return true;      // 找到了相同的值 → 返回 true
        }
    }
    return false;             // 找遍了都没找到 → 返回 false
}
```

所以 `ran(arr2, arr[price])` 的含义是：

> **判断 `arr[price]` 这个奖金，是否已经在 `arr2` 里出现过了。**

- 返回 `true` → **已经存在**（重复了）
- 返回 `false` → **还没出现过**（可以放进去）

## 为什么条件要写成 `!ran(...)`

`!` 是逻辑非，把结果取反：

| `ran(...)` 返回值 | 含义 | `!ran(...)` | 是否执行 if 里的代码 |
|---|---|---|---|
| `true` | 已经存在，重复了 | `false` | ❌ 不执行，重新抽 |
| `false` | 还没出现过 | `true` | ✅ 执行，存入 arr 2 |

所以 `if(!ran(...))` 翻译成人话就是：

> **如果这个奖金还没有被抽到过，就把它存进 `arr2`，然后 `i++` 准备存下一个。**

## 为什么要这样判断

因为这个程序的目标是**随机抽取且不重复**。如果抽到的奖金已经在 `arr2` 里了，就不能再存一次，否则 `arr2` 里会出现重复值，而且会一直填不满，导致死循环。所以必须用 `ran` 检查一遍，只有"没出现过"的才允许放进去。

## 换个写法更直观

如果觉得 `!ran(...)` 绕，可以改写成：

```java
if(ran(arr2, arr[price]) == false){
    arr2[i] = arr[price];
    i++;
}
```

或者把方法名改成 `isExist`（是否存在），语义会更清晰：

```java
if(!isExist(arr2, arr[price])){
    ...
}
```

读起来就是："如果不存在，就存进去。"
# 自然语言描述
这段代码实现了一个**随机抽奖程序**，功能是从预设的奖金数组中随机抽取所有奖金，要求不重复，最后按抽取顺序输出。

具体流程如下：

1. **准备数据**
   - 创建一个 `Random` 对象用于生成随机数。
   - 定义奖金数组 `arr`，包含 5 个奖金金额：`2, 888, 588, 1000, 10000`。
   - 创建一个空数组 `arr2`，长度与 `arr` 相同，用来存放抽取结果。

2. **随机抽取（去重）**
   - 使用 `while` 循环（实际用 `for` 循环实现，但省略了 `i++`，在内部手动递增），只要 `arr2` 还没填满就继续抽。
   - 每次随机生成一个 `0~4` 的索引 `price`，从 `arr` 中取出对应奖金。
   - 调用 `ran` 方法检查这个奖金是否已经存在于 `arr2` 中：
     - 如果已存在（返回 `true`），则跳过，重新抽。
     - 如果不存在（返回 `false`），就把它存入 `arr2[i]`，然后 `i++`，继续抽下一个。
   - 这样保证 `arr2` 中最终存放的是 `arr` 中所有奖金的一个随机排列，且不重复。

3. **输出结果**
   - 遍历 `arr2`，按抽取顺序打印每个奖金。

1. **辅助方法 `ran` **
   - 接收一个数组和一个奖金值，遍历数组检查该值是否已存在。
   - 存在返回 `true`，不存在返回 `false`。

**简单说**：就是把 5 个奖金打乱顺序随机排列，然后依次输出。
