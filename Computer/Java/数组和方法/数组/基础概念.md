3. 数字的初始化
- 静态初始化
```
int[] array=new int[]{1,2,3};
int[] array={1,2,3};
```
- 动态初始化
```
int[] array=new int[3];
```
4. 数组遍历
```
public static void main(String[] args) {  
    int[] array = new int[]{11, 12, 13};  
    for (int i = 0; i < array.length; i++) {  
        System.out.println(array[i]);  
    }  
}
```
 `array.length` 是获取数组的长度
 5. 快捷方式
