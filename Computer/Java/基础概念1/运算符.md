### **自增自减运算**

 1.单独成行
当 `a++;` 或者 `++a;` **单独作为一行代码**时，它们的作用是**一模一样**的。
*   不管 `++` 写在前面还是后面，这一行执行完，`a` 的值都会加 1。
*   **为什么？** 因为单独成行时，没有其他代码（比如打印语句）来“使用”`a` 的值，所以“先加还是后加”就没有区别了，最终结果都是 `a` 增加了 1。
eg：
```
int a=1;  
a++;  
System.out.println(a);输出2
```
2.在表达式中（参与计算时）
当自增运算符放在表达式中，**顺序就至关重要了**，这时候就要看 `++` 的位置：

*   **如果是 `a++`（后置）：** “先打印 a，再计算”。因为它的规则是“先取值，后自增”。
*   **如果是 `++a`（前置）：**“先运算，再打印”。因为它的规则是“先自增，后取值”。

*   `a++`：表达式的值是**旧值**（加 1 前的值），但 `a` 本身变成了新值。
*   `++a`：表达式的值是**新值**（加 1 后的值），`a` 本身也变成了新值。
eg：
```java
int a = 1;
int b = a++; // 因为 a++ 是后置，它把“旧值1”交给了 b，然后 a 自己变成了 2
System.out.println("a=" + a + ", b=" + b); 
// 输出结果：a=2, b=1

int c = 1;
int d = ++c; // 因为 ++c 是前置，它先让 c 变成 2，然后把“新值2”交给了 d
System.out.println("c=" + c + ", d=" + d);
// 输出结果：c=2, d=2
```

### 三元运算符
格式：
关系表达式？表达式 1：表达式 2；
eg 1：
```
int max =a>b?a:b;  
System.out.println(max);
```
eg 2
```
int a=210,b=210,c=210;  
int max1=a>=b?a:b;  
int max=max1>=c?max1:c;  
System.out.println("最高为"+max+"cm");
```
