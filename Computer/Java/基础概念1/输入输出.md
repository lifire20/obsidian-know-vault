### **键盘录入步骤**
1.导包
```
import java.util.Scanner;
```
2.创建对象
```
Scanner sc=new Scanner(System.in);
```
3.接受数据
```
int i=sc.nextInt();
```

### 键盘录入方式
- 第一种
```
nextInt();//接收整数
nextDuble();//接收小数
next();//接收字符串
```
遇到空格，制表符，回车就停止接收
- 第二种
```
nextLine();//接收字符串
```
可以接受空格，制表符，遇到回车才停止
### 输出语句
普通输出
```
//不换行输出，结果为“我爱你”
System.out.print("我");  
System.out.print("爱");  
System.out.print("你");

//换行输出"我""爱""你"
System.out.println("我");  
System.out.println("爱");  
System.out.println("你");
```
占位符`%s`输出
```
//先写输出语句，再写变量。输出：我的年龄是：18岁
int age=18;  
System.out.printf("我的年龄是：%s岁",age);

//输出语句和变量一起写
int age=18;  
System.out.printf("我的年龄是："+age+"岁");
```
