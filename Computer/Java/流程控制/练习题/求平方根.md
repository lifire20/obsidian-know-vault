问题：求一个大于等于 2 的整数的平方根，用整数输出

代码实现:
```
public static void main(String[] args) {  
        while(true){  
            System.out.println("请输入一个大于等于2的整数：");  
            Scanner sc=new Scanner(System.in);  
            int x=sc.nextInt();  
            if(x<2){  
                System.out.println("输入的数字不合法，请重新输入。");  
                continue;  
            }  
//            int num = (int) Math.sqrt(x);   引用库函数，可以省略下面一块代码，但注意强制转换的格式。  
            int num=0;  
            for(int i=0;i>=0;i++){  
  
                if((i*i)<=x&&((i+1)*(i+1))>x){  
                    num=i;  
                    break;  
                }  
            }  
  
            System.out.println("该数的平方根为："+ num);  
            break;  
        }  
  
  
    }
```
思路：从 1 开始每个数都平方，然后和要求的数比较，当这个数的平方接近所求数，并且这个数的下一个数的平方大于所求数，则求出结果。

还可以使用折半查找
[[折半查找]]
代码实现
```
package com.itheima.demo1;  
  
  
import java.util.Scanner;  
  
class demo2 {  
    public static void main(String[] args) {  
        while(true){  
            System.out.println("请输入一个大于等于2的整数：");  
            Scanner sc=new Scanner(System.in);  
            int x=sc.nextInt();  
            if(x<2){  
                System.out.println("输入的数字不合法，请重新输入。");  
                continue;  
            }  
//            int num = (int) Math.sqrt(x);   引用库函数，可以省略下面一块代码  
            int num=0;  
            int low=1;  
            int high=x;  
  
           while(low<=high){  
               int mid=low+(high-low)/2;  
               long sq = (long) mid * mid;  
                if(sq<=x){  
                    num=mid;  
                    low=mid+1;  
                } else{  
                    high=mid-1;  
                }  
            }  
            System.out.println("该数的平方根为："+ num);  
            break;  
        }  
  
  
    }  
}
```
