问题：
1-100 中，遇到包含 7 或者可以整除 7 的数字就过，否则输出数字。

---

代码实现：
```
public static void main(String[] args) {  
   for(int i=1;i<=100;i++){  
       if(i%7==0||i%10==7||i/10%10==7){  
           System.out.println("过");  
       }else{  
           System.out.println(i);  
       }  
   }  
}
```

思路：
三个条件
1.个位数 为 7。需要获得个位数，直接用这个数字对 10 取余
2.十位数为 7.直接用这个数除 10 再对 10 取余，得到十位数
3.可以整除 7.对 7 取余，为 0 则可以整除。

错误：
本题是求 1-100，范围都是两位数，所以求十位数的时候直接用这个数除 10 了，即 `i/10` ，但如果是三位数，那么直接除 10 会得到两位数，所以还得再对 10 取余得到最终的数。
==注意考虑各种情况==
