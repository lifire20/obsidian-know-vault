回文数练习
```
Scanner sc = new Scanner(System.in);  
 int x = sc.nextInt();  
int temp=x;  
int num=0;  
int ge=0;  
while(x!=0){  
    //取个位数  
    ge=x%10;  
    //变化x的值，原来的 十位数变成个位数  
    x=x/10;  
    //记录反过来的值  
    num=num*10+ge;  
}  
if(num==temp){  
    System.out.println("是回文数");  
}else{  
    System.out.println("不是回文数");  
}
```
