### **if 语句格式**
```
if(关系表达式){
语句体1
}else if(关系表达式){
语句体2
}else(){

}
```

注意：
- 如果对布尔类型变量进行判断，不用 `“==”`，直接写在小括号里即可
- if 可以嵌套
- 可以和[[运算符]]中的三元运算符联系/区别

### switch 语句
格式
```
switch(表达式){
case 值1:
	语句体1;
	break;
case 值2:
	语句体2;
	break;
	
	...
dafault:
	语句体n+1;
	break;
}
```

eg:
```
Scanner sc = new Scanner(System.in);  
int num=sc.nextInt();  
switch (num){  
    case 1:  
        System.out.println(1);  
        break;  
    case 2:  
        System.out.println(2);  
        break;  
    default:  
        System.out.println(0);  
        break;
```
注意
1.break 不要省略,否则会导致 case 穿透
如果要省略，可以用这个写法
```
Scanner sc = new Scanner(System.in);  
int num=sc.nextInt();  
switch (num){  
    case 1 ->{  
        System.out.println(1);  
      }
    case 2 ->{  
        System.out.println(2);  
      }  
    default ->{
        System.out.println(0);  
       }
```
故意穿透的用法，多个 case 共享同一段逻辑
```
switch (month) {
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        System.out.println("31 天");
        break;
    case 4: case 6: case 9: case 11:
        System.out.println("30 天");
        break;
    case 2:
        System.out.println("28 或 29 天");
        break;
}
```
