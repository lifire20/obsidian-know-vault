# 例题
3、（10 分）算法 3 是一个某二叉树问题的分支限界算法，阅读算法并回答问题。

算法 3：
```
import queue

class bitree:#二叉树结点

    def __init__(self,d,l,r):

        self.data=d

        self.lchild=l#没有左子树，则其值为None

        self.rchild=r#没有右子树，则其值为None

def traverse(T):

    q=queue.Queue()

    q.put(T)#入队

    while not q.empty():#队非空

        n=q.get()#出队

        print(n.data)

        if n.lchild!=None:

            q.put(n.lchild)

        if n.rchild!=None:

            q.put(n.rchild) 
```


（1）算法 3 的功能是什么？（3 分）
从上到下遍历二叉树，每层从左到右输出 （**二叉树的层次遍历（广度优先遍历/BFS）**）
（2）算法 3 中，用来表示活结点表的数据结构是什么？用何变量表示（4 分）
队列，变量为 q
在分支限界法中，**活结点表**就是存放待扩展结点的集合
（3）算法 3 中，约束条件是什么？(3 分)
当前结点是否存在左子树和右子树（**子结点非空**作为扩展的约束条件）

注意分支界限算法和限界剪枝的关系
## 回溯法 vs 分支限界法 在装载问题中的对比

表格

|           | 回溯法（用限界剪枝） | 分支限界法          |
| :-------- | :--------- | :------------- |
| **搜索顺序**  | 深度优先（DFS）  | 广度优先（BFS）或最优优先 |
| **活结点存储** | 栈（递归）      | 队列/优先队列        |
| **剪枝**    | 约束 + 限界    | 约束 + 限界        |
| **核心区别**  | **深度优先搜索** | **广度优先搜索**     |
