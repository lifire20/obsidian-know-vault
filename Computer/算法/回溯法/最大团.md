# 例题
（13 分）使用回溯法求解最大团问题，图以邻接矩阵存储,点数为 n。

（1）请描述解的表示方法。（2 分）
用一维数组 `x[1..n]`（或 `x[0..n-1]`），`x[i]=1` 表示顶点 `i` 在最大团中，`x[i]=0` 表示不在。
（2）请写出解空间的组织结构。（2 分）
解空间是一颗子集树，x[i]=1 或 0 表示选或不选
（**解空间是一棵子集树，树高为 `n+1`。第 `i` 层（`1 ≤ i ≤ n`）对应顶点 `i` 的决策，左分支 `x[i]=1`（选入团），右分支 `x[i]=0`（不选）。每个叶子结点对应一个候选解。**）
（3）请写出约束条件和限界条件。（4 分）
约束条件：当 i 要加入当前团，他必须和团内每个顶点都有边相连
限界条件：当前团的所有顶点数加上候选集的所有顶点数加起来**小于等于**最优团顶点数的时候，限界剪枝。
