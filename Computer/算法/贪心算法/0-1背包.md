# 例题
2、（10 分）算法 2 是一个 0-1 背包问题的贪心算法，阅读算法并回答问题。

算法 2：

```
def knapsnap 01(w,v,c):#w,v,c 分别为物品的重量列表、价值列表，和背包的容量

    n=len(w)

    rc=c

    idx=list(range(n))#idx值为0~n-1

    idx.sort(key=lambda i:v[i]/w[i],reverse=True)

    #生成一个降序索引，idx[0]为单位重量价值最大的物品号

    x=[0]*n

    for i in idx:

        if rc<w[i]:

            break

        rc-=w[i]

        x[i]=1

    return x
```
（1）算法 2 的贪心策略是什么？（3 分）
观察问题特征：要找到背包所能容纳的最大价值的放置物品策略，需要让每次防止的物品价值尽可能大。
提出贪心策略：可以每次都选择单位重量下价值最大的物品，从高到低放入。
（2）请分析在算法 2 中，变量 x 的功能是什么?（3 分）
`x` 是解向量，记录每个物品的选取状态（0 或 1），表示最终的物品放置方案
请设计一个反例，用该算法无法对其求出最优解。（4 分）
w=【3，6，6】
v=【9，12，18】
背包容量 13.
三个物品的性价比分别为 3，2，3.
按照贪心策略，应该首先放入一号物品，此时背包容量剩余 10，只能放入一个二号或者一个三号，三号性价比最高，所以最终放入一号和三号物品，价值为 27.但是实际上背包可以放入的最大价值是 30（二号和三号同时放入），所以该算法不能求出最优解。
