算法 1：

def binarySearch 2(array, left, right, target): array 为升序序列
```
if (left <= right):

        mid = (left + right) // 2

        # 搜索到对应元素

        if array[mid] == target:

            return mid

        elif array[mid] < target:

            #设定左边界为mid + 1，搜索右半边

            return binarySearch2(array, mid + 1, right, target)

        else:

            #设定右边界为mid - 1，搜索左半边

            return binarySearch2(array, left, mid - 1, target)

    else:

        return -1
```

（2）算法 1 的功能是什么？（4 分）
在**升序数组** `array` 的 `[left, right]` 区间内，查找目标元素 `target`  。若找到则返回其下标，若未找到则返回 **-1**。
在 array 里查找 target。

（3）请改用自然语言描述算法 1。（4 分）

算法首先检查搜索区间是否有效（`left <= right`）。若有效，则取区间中间位置 `mid`，将 `array[mid]` 与目标值 `target` 比较：

- 若相等，则返回 `mid`（找到目标，返回其下标）；
- 若 `array[mid] < target`，说明目标在右半区间，递归在 `[mid+1, right]` 中继续查找；
- 若 `array[mid] > target`，说明目标在左半区间，递归在 `[left, mid-1]` 中继续查找。

若区间无效（`left > right`），说明未找到目标，返回 -1。
