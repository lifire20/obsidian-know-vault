# 例题
1、（10 分）算法 1 描述了一个求主元素问题的随机化算法，阅读算法并回答问题。

算法 1：

```
import random as rd

def majority(L):

    n=len(L)

    e=L[rd.randint(0,n)]#位置A

    c=0

    for x in L:

        if e==x:

            c+=1

    return c*2>n
```

（1）如果输入序列为[2,4,1,4,2,4,6,2,5,6]，算法 1 的返回值是什么？该结果是否正确（3 分）

答：返回 false，结果正确  

（2）如果输入序列为[2,2,1,4,2,4,6,2,2,2]，则位置 A 处生成的随机数分别为 3 和 4（下标自 0 始），算法返回值分别是什么？这两个结果是否正确？（4 分）

答：false，true，随机数为 3 时结果错误，随机数为 4 时结果正确

（3）结合 1、2，请总结算法运行结果是正确解和错误解的情形。（3 分）

答：正确解：随机选中的元素就是主元素（若存在），或序列无主元素
错误解：序列存在主元素，但随机选中的是非主元素
