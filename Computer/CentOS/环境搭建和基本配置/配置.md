## 语言切换
首先使用管理员登陆，右键虚拟机桌面，点击最下面那个Open Terminal（终端打开）
![[Pasted image 20260324195745.png]]
然后运行su root命令，输入密码进入管理员（root）模式
![[Pasted image 20260324200051.png]]
然后输入localectl status查看语言，这里会输出下图结果
![[Pasted image 20260324195929.png]]
这表示是英文模式，如果想切换成英文，就输入
sudo localectl set-locale LANG=zh_CN.UTF-8
这个命令是切换成中文模式
然后再检验一下就成功切换语言了
![[Pasted image 20260324200230.png]]
运行reboot重启虚拟机，就变成中文了
下图是中文界面

## 网络配置

分为两种模式，一般情况下都是第一种，我直接按照第一种来说明，不多赘述。
首先运行
ping www.baidu.com
来检测网络连通性，出现以下界面即为成功（需要手动Ctrl+c来停止输出）
![[Pasted image 20260324201507.png]]
如果没有出现上面界面，就输入命令
cd /etc/sysconfig/network-scripts/
进入网络脚本目录
然后输入
vim ifcfg-ens33
编辑网卡文件
输入i可以检查修改内容，确保以下两项设置正确
BOOTPROTO=dhcp
ONBOOT=yes
然后按 Esc 键，输入 :wq 回车（这一步是保存）
![[Pasted image 20260324202259.png]]
![[Pasted image 20260324202227.png]]然后输入命令
service network restart
重启网络服务
最后再次用
ping www.baidu.com
来测试

成功ping百度之后，可以开始更改yum源

## 允许root用户远程登陆
运行命令
vim /etc/ssh/sshd_config
来编辑SSH配置文件
找到 # PermitRootLogin yes 改为 -> PermitRootLogin yes (约第 38 行)
找到 # PasswordAuthentication yes 改为 -> PasswordAuthentication yes (约第 65 行)
（就是去掉前面的井号就行了）

![[Pasted image 20260325170540.png]]![[Pasted image 20260325170827.png]]
摁ESC，再摁：wq保存退出
运行
systemctl restart sshd
重启SSH服务
再运行
ifconfig
查看本机ip（图中黑色部分就是ip）
![[Pasted image 20260325171134.png]]
然后开始再Windows上尝试连接
在打开Windows上打开Xshell工具（需要提前安装）
点进左上角的新建连接
![[Pasted image 20260325171406.png]]
名称自定义，主机填ip
![[Pasted image 20260325171523.png]]
然后点击确定，双击打开这个连接，在弹出来的界面中点击“接受并保存”，然后以root用户名登录
![[Pasted image 20260325171902.png]]
输入密码，就成功登陆了
![[Pasted image 20260325172222.png]]
