# 阿尼亚 · Obsidian 研究与生活主页

一个可以从空白开始使用的 Obsidian 模板库，保留阿尼亚风格主页、番茄钟、待办、习惯打卡、饮水、三餐、睡眠打卡、月历、研究区、阅读书架、音乐和日历。

**使用方法：** 在 Obsidian 中选择“打开本地仓库”，打开本文件夹，启用随附社区插件，再进入 `00.主页/主页.md`。详细步骤见 [使用说明](使用说明.md)。

**空白模板：** 不含个人文献、项目资料、待办、生活记录、账号、令牌或私人歌单。文献与项目目录只是通用骨架。

已附 Dataview、Homepage、Full Calendar Remastered 和 Tokyo Night 主题。支持 Obsidian 1.13+；日期与睡眠打卡使用北京时间，日记文件使用中文星期名称。

复制整个文件夹时保留隐藏的 `.obsidian` 配置。建议复制一份作为日常仓库，保留原模板用于分享。组件版本与来源见 [第三方组件说明](第三方组件说明.md)。
