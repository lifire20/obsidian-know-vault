好的！**排列树**是回溯法中另一种常见的解空间树，和子集树是“兄弟关系”。我帮你彻底分清它们。

---

## 一、排列树长什么样？

**排列树**用来解决**“选哪些元素，并且按什么顺序排列”**的问题。

比如：从 n 个元素中选出 m 个，并且**考虑顺序**（排列），所有可能的排列构成解空间。

---

## 二、举个直观例子

假设有 3 个元素 {1,2,3}，要求**全排列**（所有可能的顺序）：

```
123, 132, 213, 231, 312, 321
```

一共 3! = 6 个。

排列树是这样组织的（从根开始，每层选一个还没用过的元素）：

```
                    根
        /            |            \
      选1           选2           选3
    /     \       /     \       /     \
  选2     选3   选1     选3   选1     选2
   |       |     |       |     |       |
  选3     选2   选3     选1   选2     选1
 123     132    213     231   312     321
```

每个叶子节点就是一个完整的排列。

## 三、子集树 vs 排列树（考试重点对比）

| 对比项 | **子集树** | **排列树** |
|--------|-----------|-----------|
| **解决什么问题** | 从 n 个元素中选一个**子集**（不考虑顺序） | 从 n 个元素中选一个**排列**（考虑顺序） |
| **典型问题** | 最大团、0-1 背包、子集和 | 旅行商问题（TSP）、N 皇后、任务分配 |
| **叶子节点数** | 2ⁿ 个 | n! 个 |
| **每层做什么** | 决定当前元素 **选/不选**（2 个分支） | 决定当前位置放**哪个未用元素**（分支数递减） |
| **树的结构** | 每个节点最多 2 个孩子（左/右） | 第 1 层 n 个孩子，第 2 层 n-1 个，... |
| **深度** | n 层 | n 层 |

---

## 四、帮你记两个“标签”

- **子集树** → 关键词：**“选或不选”**（0/1 决策）
- **排列树** → 关键词：**“谁放前面”**（顺序决策）

看到题目问“解空间组织结构”，你就看：
- 如果是“选哪些顶点” → **子集树**
- 如果是“访问顺序/排列顺序” → **排列树**

## 五、排列树的回溯模板（扩展知识）

如果你以后写排列树回溯，一般会这样：

```c
void backtrack(int t) {  // t 表示当前填第 t 个位置
    if (t > n) {
        // 得到一个完整排列，处理
        return;
    }
    for (int i = t; i <= n; i++) {
        swap(x[t], x[i]);   // 把第 i 个元素放到第 t 个位置
        backtrack(t + 1);
        swap(x[t], x[i]);   // 回溯，换回来
    }
}
```

## 六、回到你的最大团题目

最大团问题是：
> 从 n 个顶点中选一个子集，要求内部全相连。

**不关心顺序**，只关心“哪些顶点在里面”，所以是 **子集树**，不是排列树。

所以你题目（2）答案写 **子集树** 就对了。
