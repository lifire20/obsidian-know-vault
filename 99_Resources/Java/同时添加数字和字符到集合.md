如果想在同一个 `ArrayList` 里同时存数字和字符，核心思路是：**让它们的类型统一**。常见有几种做法：

## 方法一：用 `Object` 作为泛型

```java
ArrayList<Object> list = new ArrayList<>();
list.add(123);        // int 自动装箱成 Integer
list.add('A');        // char 自动装箱成 Character
list.add("hello");    // String 也可以

for (Object o : list) {
    System.out.println(o);
}
```

缺点：取出来时是 `Object`，需要自己判断类型再强转：

```java
for (Object o : list) {
    if (o instanceof Integer) {
        int n = (Integer) o;
    } else if (o instanceof Character) {
        char c = (Character) o;
    }
}
```

## 方法二：统一转成 `String` 存

如果只是展示、拼接，不需要保留原始类型：

```java
ArrayList<String> list = new ArrayList<>();
list.add(String.valueOf(123));  // "123"
list.add(String.valueOf('A'));  // "A"
```

## 方法三：用 `Number`（只适合数字类）

`Integer`、`Double`、`Long` 都是 `Number` 的子类，但 `Character` 不是，所以这种**不能同时存字符**：

```java
ArrayList<Number> list = new ArrayList<>();
list.add(123);
list.add(3.14);
```

## 方法四：自定义一个包装类（推荐，类型安全）

```java
class Item {
    private final Object value;
    public Item(Object value) { this.value = value; }
    public Object getValue() { return value; }
}

ArrayList<Item> list = new ArrayList<>();
list.add(new Item(123));
list.add(new Item('A'));
```

## 怎么选？

| 场景 | 推荐 |
|------|------|
| 只是临时混存、能接受强转 | `ArrayList<Object>` |
| 只做字符串展示 | `ArrayList<String>` |
| 想要类型安全、可扩展 | 自定义包装类 |
| 只存数字 | `ArrayList<Number>` |

**最常用、最直接的就是 `ArrayList<Object>` **，因为 Java 里所有类型（包括包装类）都继承自 `Object`，加进去会自动装箱。需要注意的是取出时要判断类型，否则容易 `ClassCastException`。
