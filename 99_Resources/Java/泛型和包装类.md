这是个很好的问题，两者经常一起出现，但**根本不是同一个层面的东西**。可以用一句话概括：

> **泛型是“语法机制”，包装类是“具体的类”。它们解决的是完全不同的问题，只是经常配合使用。**

---

## 一、本质区别

| | 泛型（Generics） | 包装类（Wrapper Class） |
|---|---|---|
| 是什么 | 一种**语法/类型参数机制** | 一组**具体的 Java 类** |
| 解决什么问题 | 让代码**类型安全**、可复用，避免强转 | 让**基本类型能当对象用** |
| 出现在哪 | `ArrayList<Integer>` 里的 `<Integer>` | `Integer`、`Character`、`Double` … |
| 是不是类 | 不是类，是类型参数 | 是实实在在的类 |
| 数量 | 概念，无数种写法 | 固定 8 个（对应 8 种基本类型） |

---

## 二、包装类是什么

Java 有 8 种基本类型，它们**不是对象**，不能直接放进集合（集合只能存对象）。所以每种基本类型都有一个对应的“包装类”：

| 基本类型 | 包装类 |
|---|---|
| int | `Integer` |
| char | `Character` |
| double | `Double` |
| boolean | `Boolean` |
| byte | `Byte` |
| short | `Short` |
| long | `Long` |
| float | `Float` |

```java
Integer a = 123;   // 自动装箱：int → Integer
int b = a;         // 自动拆箱：Integer → int
```

包装类的作用：**把基本类型变成对象**，这样才能放进集合、参与泛型、调用方法（如 `a.toString()`）。

---

## 三、泛型是什么

泛型是给类/方法**加一个“类型参数”**，让它在使用时才确定具体类型：

```java
ArrayList<Integer> list = new ArrayList<>();
```

这里的 `<Integer>` 就是泛型参数，意思是“这个 list 只能装 Integer”。

- `<Integer>`、`<String>`、`<Object>` 都是泛型的**具体写法**
- `T`、`E`、`K`、`V` 是泛型的**占位符**

```java
// 自定义泛型类
class Box<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

Box<Integer> b1 = new Box<>();  // T = Integer
Box<String>  b2 = new Box<>();  // T = String
```

泛型的作用：**编译期检查类型**，避免运行时强转出错。

---

## 四、两者的关系（关键）

它们经常一起出现，是因为：

> **泛型只能写“类类型”，不能写基本类型。所以要用基本类型时，必须用它的包装类。**

```java
ArrayList<int>    list;  // ❌ 编译错误！泛型里不能写基本类型
ArrayList<Integer> list; // ✅ 必须用包装类
```

这就是为什么你上一个问题里会看到 `ArrayList<Integer>` 而不是 `ArrayList<int>`。

- **泛型**：规定了“这个集合只能装 Integer”
- **包装类**：让 int 能变成对象装进去

两者一配合，才实现了“类型安全的整数集合”。

---

## 五、一个类比

把集合想象成一个**只能放盒子的仓库**：

- **包装类** = 把散装的东西（基本类型）装进盒子里，才能入库
- **泛型** = 仓库门口贴的标签，规定“本仓库只收 X 类盒子”

标签（泛型）本身不装东西，盒子（包装类）才是实际被装进去的。

---

## 六、容易混淆的点

1. ** `Integer` 是类，`<Integer>` 是泛型写法**——前者是包装类，后者是“把 Integer 作为类型参数传给泛型”。
2. **泛型不是类**，`ArrayList<Integer>` 整体才是一个类型，`<Integer>` 只是它的参数。
3. ** `Object` 不是包装类**，它是所有类的父类，常被用来做“万能泛型” `ArrayList<Object>`。

---

**总结一句话：**
包装类解决“基本类型不能当对象”的问题；泛型解决“类型不安全、要强转”的问题。泛型里要用基本类型时，就得靠包装类——这就是它俩唯一的交集。
