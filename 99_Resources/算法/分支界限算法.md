## 1. 什么是分支限界算法？

想象你在一个迷宫里找宝藏，有很多条路可以走。  
你不想一条路走到黑才发现是死路，而是想**有策略地搜索**，尽快找到最好的宝藏。

**分支限界算法**就是这样一个"聪明"的搜索方法：
- **分支**：把大问题分成小问题（像岔路口）
- **限界**：估算每条路最多能得到多好的结果，放弃那些"不可能更好"的路

## 2. 核心思想

用一个**例子**来理解：

假设你要从家去学校，有很多条路：
- 路A：前1公里很堵（估计要30分钟）
- 路B：前1公里很顺（估计只要10分钟）

你会先探索路B，因为它看起来更有希望。

**关键点**：
1. 维护一个**优先队列**（总是先探索"看起来最好"的路径）
2. 计算每个分支的**上界**（最多能得多少分）或**下界**（最少会花多少钱）
3. 如果某个分支的上界还不如已经找到的最好解，就**剪枝**（不再探索）

## 3. 用0-1背包问题讲解分支限界

这是最经典的例子！

### 问题
```
背包容量 C = 10
物品1: 重量6，价值30  (性价比5)
物品2: 重量5，价值20  (性价比4)
物品3: 重量5，价值15  (性价比3)
```

### 算法步骤

#### 第一步：按性价比排序
排序后：
```
物品1: 重6，价30，性价比5
物品2: 重5，价20，性价比4
物品3: 重5，价15，性价比3
```

#### 第二步：创建状态树
每个状态记录：
- 当前选了哪些物品
- 当前总价值
- 当前总重量
- **上界**（最多还能得到多少价值）

#### 第三步：计算上界
**上界 = 当前价值 + 剩余容量的最大可能价值**

计算方法：用贪心（可以拿部分）估算剩余物品最多值多少。

#### 第四步：搜索过程

```
初始状态: 价值0，重量0，剩余容量10
上界 = 0 + 用贪心算剩余物品的价值

估算: 物品1全拿(30)，剩余4容量拿物品2的一部分(4/5*20=16)
上界 = 0 + 30 + 16 = 46
```

把初始状态加入优先队列（按上界从大到小排）

**第1轮**：探索初始状态
- **分支1（拿物品1）**：
  ```
  价值30，重量6，剩余4
  上界 = 30 + 物品2的一部分(4/5*20=16) = 46
  ```
- **分支2（不拿物品1）**：
  ```
  价值0，重量0，剩余10
  上界 = 0 + 物品2全拿(20) + 物品3全拿(15) = 35
  ```

两个分支都加入队列，上界高的优先。

**第2轮**：探索分支1（价值30，上界46）
- **分支1.1（拿物品2）**：
  ```
  重量6+5=11 > 10 ❌ 不可行，丢弃
  ```
- **分支1.2（不拿物品2）**：
  ```
  价值30，重量6，剩余4
  上界 = 30 + 物品3的一部分(4/5*15=12) = 42
  ```

**第3轮**：探索分支1.2（价值30，上界42）
- **分支1.2.1（拿物品3）**：
  ```
  重量6+5=11 > 10 ❌ 不可行
  ```
- **分支1.2.2（不拿物品3）**：
  ```
  价值30，重量6 → 得到一个完整解！
  更新最好解 = 30
  ```

**第4轮**：探索分支2（价值0，上界35）
- 上界35 < 当前最好解30？  
  等等，35 > 30，还有希望，继续探索！

- **分支2.1（拿物品2）**：
  ```
  价值20，重量5，剩余5
  上界 = 20 + 物品3全拿(15) = 35
  ```

- **分支2.2（不拿物品2）**：
  ```
  价值0，重量0，剩余10
  上界 = 0 + 物品3全拿(15) = 15  ← 小于最好解30，剪枝！
  ```

**第5轮**：探索分支2.1（价值20，上界35）
- **分支2.1.1（拿物品3）**：
  ```
  价值35，重量10 → 更好解！更新最好解 = 35
  ```
- **分支2.1.2（不拿物品3）**：
  ```
  价值20，重量5，上界=20  ← 小于35，剪枝
  ```

**找到最优解：35（拿物品2和3）**

## 4. 可视化搜索树

```
                    [0, 0, 上界46]
                    /            \
                   /              \
           拿物品1                不拿物品1
          [30,6,46]              [0,0,35]
           /      \               /     \
      拿物品2   不拿物品2      拿物品2  不拿物品2
      (不可行)  [30,6,42]     [20,5,35] [0,0,15✂️]
                /      \         /    \
           拿物品3  不拿物品3  拿物品3 不拿物品3
          (不可行) [30,6,30]  [35,10✅] [20,5,20✂️]
                   找到解35
```

## 5. 分支限界 vs 其他算法

| 算法 | 特点 | 优点 | 缺点 |
|------|------|------|------|
| **贪心** | 只顾眼前 | 飞快 | 不一定最优 |
| **动态规划** | 填表格 | 保证最优 | 空间大 |
| **回溯法** | 深度优先 | 能找到所有解 | 可能很慢 |
| **分支限界** | 广度优先+剪枝 | 保证最优，比回溯快 | 需要估算函数 |

## 6. 关键要点

1. **上界函数**很重要：估算越准，剪枝越多，越快
2. **优先队列**：总是先探索最有希望的分支
3. **剪枝**：放弃不可能更好的分支
4. **保证最优**：因为只有不可能更好的才剪掉

## 7. 生活中的例子

**找餐厅吃饭**：
- 你设定时间限制1小时
- 先估算每家餐厅（看评论、距离）
- 放弃那些"评论差+距离远"的（上界很低）
- 重点探索看起来最好的几家
