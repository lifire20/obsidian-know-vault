## 标准快速排序（固定选 pivot）[[分治法]]

### 核心思想

**选一个基准数（pivot），把数组分成两部分：**
- 左边：都比 pivot 小
- 右边：都比 pivot 大

然后递归处理左右两边。

---

### 举个例子

数组：`[3, 6, 2, 8, 1, 4]`

**第一步：选 pivot**

通常选**最后一个元素**作为 pivot：`pivot = 4`

**第二步：partition（分区）**

从左到右遍历，把比 4 小的放左边，比 4 大的放右边：

```
[3, 2, 1, | 4, | 6, 8]
  小        pivot   大
```

**第三步：递归**

- 左边 `[3, 2, 1]` 继续排序
- 右边 `[6, 8]` 继续排序

---

### 代码（最简版）

```python
def quicksort(L, low, high):
    if low >= high:
        return
    
    # 固定选最后一个当 pivot
    pivot = L[high]
    
    # i 指向"小数字区域的边界"
    i = low
    for j in range(low, high):
        if L[j] < pivot:
            L[i], L[j] = L[j], L[i]  # 小的放左边
            i += 1
    
    # 把 pivot 放到中间
    L[i], L[high] = L[high], L[i]
    
    # 递归左右两边
    quicksort(L, low, i - 1)
    quicksort(L, i + 1, high)
```

---

## 问题：固定选 pivot 的坑

如果数组**已经有序**：`[1, 2, 3, 4, 5, 6]`

每次都选最后一个当 pivot，partition 后：
- 左边：`[1, 2, 3, 4, 5]`（5 个元素）
- 右边：`[]`（0 个元素）

**递归深度 = n，时间复杂度退化为 O(n²)**

---

## 随机快速排序（解决这个坑）

**唯一区别**：选 pivot 时**随机选一个位置**，而不是固定选最后一个。

```python
import random

def randomized_quicksort(L, low, high):
    if low >= high:
        return
    
    # ========== 就改这里 ==========
    # 随机选一个位置，跟最后一个交换
    rand_idx = random.randint(low, high)
    L[rand_idx], L[high] = L[high], L[rand_idx]
    # =============================
    
    pivot = L[high]  # 现在"最后一个"其实是随机选的那个
    
    # 下面 partition 完全一样
    i = low
    for j in range(low, high):
        if L[j] < pivot:
            L[i], L[j] = L[j], L[i]
            i += 1
    
    L[i], L[high] = L[high], L[i]
    
    randomized_quicksort(L, low, i - 1)
    randomized_quicksort(L, i + 1, high)
```

---

## 对比

| | 标准快排 | 随机快排 |
|--|---------|---------|
| **选 pivot** | 固定选最后一个 | 随机选一个 |
| **最坏情况** | 输入有序时 O(n²) | 概率极低，期望 O(n log n) |
| **排序结果** | 正确 | 正确 |
| **运行时间** | 可能很慢 | 期望很快 |

---

## 一句话总结

> **随机快排 = 标准快排 + 随机选 pivot**
> 
> 排序结果永远是对的（拉斯维加斯），但运行时间靠随机"赌运气"，期望是 O(n log n)。
