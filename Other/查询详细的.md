## 实验一：淘宝用户行为数据分析

### 数据概况
- **原始数据**：`Processed_UserBehavior.csv`（100 万条）
- **Hive 表**：`taobao_raw_string`（外部表，直接读取 HDFS CSV）
- **MySQL 表**：`behavior_stats`、`daily_trend`、`item_top10`、`user_top10`
- **HBase 表**：`item_top10`、`user_top10`

---

### 1. MySQL 查询

登录 MySQL：
```bash
mysql -u root -p
```

```sql
USE taobao;

-- 1.1 总数查询：查看所有表记录数
SELECT 'behavior_stats' AS table_name, COUNT(*) AS row_count FROM behavior_stats
UNION ALL
SELECT 'daily_trend', COUNT(*) FROM daily_trend
UNION ALL
SELECT 'item_top10', COUNT(*) FROM item_top10
UNION ALL
SELECT 'user_top10', COUNT(*) FROM user_top10;

-- 1.2 行为类型统计（查所有数据）
SELECT * FROM behavior_stats;

-- 1.3 每日趋势（查前20条）
SELECT * FROM daily_trend ORDER BY dt LIMIT 20;

-- 1.4 商品购买 TOP10
SELECT * FROM item_top10 ORDER BY buy_cnt DESC;

-- 1.5 用户购买 TOP10
SELECT * FROM user_top10 ORDER BY buy_cnt DESC;

-- 1.6 验证数据完整性：检查是否有 NULL 或异常值
SELECT COUNT(*) FROM daily_trend WHERE dt IS NULL OR behavior_type IS NULL;
```

退出 MySQL：
```sql
EXIT;
```

---

### 2. Hive 查询

启动 Hive：
```bash
hive
```

```sql
-- 2.1 使用数据库
USE default;

-- 2.2 总数查询：原始数据总行数
SELECT COUNT(*) FROM taobao_raw_string;

-- 2.3 查看前10条原始数据
SELECT * FROM taobao_raw_string LIMIT 10;

-- 2.4 行为类型分布（直接查原始表）
SELECT behavior_type, COUNT(*) AS cnt 
FROM taobao_raw_string 
WHERE behavior_type IN ('fav', 'cart', 'buy')
GROUP BY behavior_type;

-- 2.5 每日趋势（前20天）
SELECT SUBSTR(event_time_str, 1, 10) AS dt, behavior_type, COUNT(*) AS cnt
FROM taobao_raw_string
WHERE behavior_type IN ('fav', 'cart', 'buy')
GROUP BY SUBSTR(event_time_str, 1, 10), behavior_type
ORDER BY dt LIMIT 20;

-- 2.6 商品购买 TOP10（直接从原始表查）
SELECT item_id, COUNT(*) AS buy_cnt
FROM taobao_raw_string
WHERE behavior_type = 'buy'
GROUP BY item_id
ORDER BY buy_cnt DESC
LIMIT 10;

-- 2.7 用户购买 TOP10
SELECT user_id, COUNT(*) AS buy_cnt
FROM taobao_raw_string
WHERE behavior_type = 'buy'
GROUP BY user_id
ORDER BY buy_cnt DESC
LIMIT 10;

-- 2.8 查看结果表（如果已创建）
SELECT * FROM behavior_stats_result;
SELECT * FROM daily_trend_result LIMIT 20;
SELECT * FROM item_top10_result;
SELECT * FROM user_top10_result;
```

退出 Hive：
```sql
EXIT;
```

### 3. HBase 查询

启动 HBase Shell：
```bash
hbase shell
```

```hbase
-- 3.1 查看所有表
list

-- 3.2 查看商品 TOP10 表
scan 'item_top10'

-- 3.3 查看用户 TOP10 表
scan 'user_top10'

-- 3.4 查询特定商品（例如 item_id=123456，换成实际存在的 ID）
get 'item_top10', '123456'

-- 3.5 查询特定用户（例如 user_id=98765）
get 'user_top10', '98765'

-- 3.6 只查看前5条（避免显示太多）
scan 'item_top10', {LIMIT => 5}
scan 'user_top10', {LIMIT => 5}

-- 3.7 查看表结构
describe 'item_top10'
describe 'user_top10'

-- 3.8 统计行数（HBase 没有内置 count，需要扫描）
count 'item_top10'
count 'user_top10'
```

退出 HBase Shell：
```hbase
exit
```

## 实验二：网站用户行为分析（厦门大学案例）

### 数据概况
- **原始数据**：`small_user.csv`（30 万条）或 `raw_user.csv`（2000 万条）
- **Hive 表**：`dblab.bigdata_user`（外部表）
- **MySQL 表**：`behavior_dist`、`item_category_top10`、`monthly_buy`、`scan`
- **HBase 表**：`user_action`

---

### 1. MySQL 查询

登录 MySQL：
```bash
mysql -u root -p
```

```sql
USE dblab;

-- 1.1 总数查询：查看所有表记录数
SELECT 'behavior_dist' AS table_name, COUNT(*) AS row_count FROM behavior_dist
UNION ALL
SELECT 'item_category_top10', COUNT(*) FROM item_category_top10
UNION ALL
SELECT 'monthly_buy', COUNT(*) FROM monthly_buy
UNION ALL
SELECT 'scan', COUNT(*) FROM scan;

-- 1.2 行为分布
SELECT * FROM behavior_dist;

-- 1.3 商品分类购买 TOP10
SELECT * FROM item_category_top10 ORDER BY buy_cnt DESC;

-- 1.4 月度购买量
SELECT * FROM monthly_buy ORDER BY month;

-- 1.5 省份浏览统计（全部）
SELECT * FROM scan ORDER BY scan_cnt DESC;

-- 1.6 查看省份浏览 TOP10
SELECT province, scan_cnt FROM scan ORDER BY scan_cnt DESC LIMIT 10;

-- 1.7 统计总浏览数
SELECT SUM(scan_cnt) FROM scan;
```

退出 MySQL：
```sql
EXIT;
```

---

### 2. Hive 查询

启动 Hive：
```bash
hive
```

```sql
-- 2.1 使用数据库
USE dblab;

-- 2.2 总数查询：原始数据总行数
SELECT COUNT(*) FROM bigdata_user;

-- 2.3 查看前10条原始数据
SELECT * FROM bigdata_user LIMIT 10;

-- 2.4 行为类型分布（1-浏览, 2-收藏, 3-加购物车, 4-购买）
SELECT behavior_type, COUNT(*) AS cnt 
FROM bigdata_user 
GROUP BY behavior_type;

-- 2.5 购买行为总数
SELECT COUNT(*) FROM bigdata_user WHERE behavior_type = 4;

-- 2.6 商品分类购买 TOP10
SELECT item_category, COUNT(*) AS buy_cnt
FROM bigdata_user
WHERE behavior_type = 4
GROUP BY item_category
ORDER BY buy_cnt DESC
LIMIT 10;

-- 2.7 月度购买量
SELECT SUBSTR(visit_date, 1, 7) AS month, COUNT(*) AS buy_cnt
FROM bigdata_user
WHERE behavior_type = 4
GROUP BY SUBSTR(visit_date, 1, 7)
ORDER BY month;

-- 2.8 省份浏览统计
SELECT province, COUNT(behavior_type) AS scan_cnt
FROM bigdata_user
WHERE behavior_type = 1
GROUP BY province
ORDER BY scan_cnt DESC;

-- 2.9 查询特定用户（例如 uid=10001082）
SELECT * FROM bigdata_user WHERE uid = '10001082' LIMIT 20;

-- 2.10 查询特定日期的数据
SELECT * FROM bigdata_user WHERE visit_date = '2014-12-12' LIMIT 20;

-- 2.11 查看已创建的结果表
SHOW TABLES LIKE '%_hive';
SELECT * FROM behavior_distribution_hive;
SELECT * FROM item_category_top10_hive;
SELECT * FROM monthly_buy_hive;
SELECT * FROM scan_hive;
```

退出 Hive：
```sql
EXIT;
```

---

### 3. HBase 查询

启动 HBase Shell：
```bash
hbase shell
```

```hbase
-- 3.1 查看所有表
list

-- 3.2 查看 user_action 表（如果已导入）
scan 'user_action', {LIMIT => 10}

-- 3.3 查看特定行（例如 rowkey=1）
get 'user_action', '1'

-- 3.4 查看特定行的指定列族
get 'user_action', '1', {COLUMN => 'f1'}

-- 3.5 查看特定列（例如 uid）
get 'user_action', '1', {COLUMN => 'f1:uid'}

-- 3.6 扫描并只显示特定列
scan 'user_action', {COLUMNS => ['f1:uid', 'f1:behavior_type'], LIMIT => 10}

-- 3.7 查看表结构
describe 'user_action'

-- 3.8 统计行数
count 'user_action'

-- 3.9 如果导入了 item_top10 和 user_top10（可选）
scan 'item_top10'
scan 'user_top10'
```

退出 HBase Shell：
```hbase
exit
```

## 快速验证脚本（一键检查）

如果你想快速验证所有数据，可以创建一个 Shell 脚本：

```bash
nano check_all.sh
```

```bash
#!/bin/bash
echo "========== MySQL Checks =========="
mysql -u root -p123456 -e "USE taobao; SELECT 'taobao' AS db, COUNT(*) FROM behavior_stats UNION ALL SELECT 'taobao', COUNT(*) FROM daily_trend;"
mysql -u root -p123456 -e "USE dblab; SELECT 'dblab' AS db, COUNT(*) FROM behavior_dist UNION ALL SELECT 'dblab', COUNT(*) FROM scan;"

echo "========== Hive Checks =========="
hive -e "USE default; SELECT COUNT(*) FROM taobao_raw_string;"
hive -e "USE dblab; SELECT COUNT(*) FROM bigdata_user;"

echo "========== HBase Checks =========="
echo "list" | hbase shell | grep -E "item_top10|user_action"
```

> 记得把 `-p123456` 换成你的 MySQL 密码。
